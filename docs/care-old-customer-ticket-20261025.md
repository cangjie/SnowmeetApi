# 养护开单默认选择老顾客券（2026-10-25）

用户要求：顾客账户有老顾客券时，养护开单自动选中。

## 小程序

- 原养护表单使用现有 `Ticket/GetMemberTicketsByStaff`，参数为当前会员、养护业务和 `canUse=true`，由服务端统一过滤未启用、过期、已使用和作废券。自动选择模板 16 的老顾客券，临近到期优先。
- 一张券只分配一件装备；已有券、会员卡、质保/招待和新购卡模式保留原选择。店员手动选择“不使用”后，不会被异步返回或重新渲染再次勾上；新装备仍可自动选用剩余券。
- 自动选券只带入券对象与券码，保留已选项目、维修和手动减免；通过原计价接口更新优惠金额并保存草稿。
- 当前会员的列表请求复用；切换顾客丢弃旧响应，清空订单后重新读可用券。草稿首次保存换主键后，保留店员的手选决定。
- 点击去结算时等待自动选券及优惠计价完成，避免列表晚到漏减优惠；等待期间阻止重复点击。已提交购卡单仍可重试进入原结算页。

## 服务端交互修复

普通养护使用老顾客券后，`care.discount` 包含券带出的减免。从普通养护切换到新购卡时原实现清除券码，却可能将这个金额当成店员手动减免抵扣卡外项目。

购卡试算现在先按原项目和老顾客券计算券优惠：原减免不超过该优惠时清零，超过时保留较大的店员手动减免。试算只读，确认保存后才清券和落新费用；后续试算结果保持一致。回归覆盖卡款 0.01 加附加费 0.01 实收 0.02、较大手动减免保留、同单支付发卡扣次，以及老顾客券保持未使用。

不增加表或列，无结构 SQL；原优惠券接口、普通养护下单和单订单购卡接口契约均保留。自动勾选属于小程序表单行为，需更新小程序才能使用；服务端修改只负责切换购卡时的减免兼容。
