# 会员装备本雪季首养照片

用户要求装备列表标题图使用本雪季第一次养护照片；雪季为每年 10 月 1 日至次年 9 月 30 日。

按读取时计算封面：已有明确装备 ID 或唯一来源养护 ID 的记录精确关联；其他历史未关联记录仅在同会员、类型、品牌、长度唯一匹配时关联。选择第一条有效未取消养护及其第一张有效普通照片，排除维修前后照片与视频；无可用照片时沿用档案图。按养护创建时间、养护 ID、照片 ID 确定顺序；不选未来记录。

保留已有档案照片及编辑接口，新增独立封面 URL 字段供列表显示；不回写数据库、不改手动照片、旧客户端保留原字段。不同装备存在相同历史匹配条件时不猜测；已删除的同规格装备也计入歧义检查。部署及小程序发布按用户现有安排。
